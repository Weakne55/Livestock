# Тестирование и проверенный статус

## 1. Unit-тесты (до запуска реальных данных)

```bash
cd ~/livestock
conda activate livestock-snakemake
python -m unittest discover -s tests -v
```

Проверяются манифест, модульность DAG, ресурсы, профили и отдельные скрипты. Зафиксировано **29 успешных unit-тестов** после подготовки документации. Они **не** заменяют интеграционного запуска.

## 2. Проверка собственных входов

Создайте YAML и TSV по [инструкции](INSTALL_RU.md#сценарий-б-пайплайн-уже-установлен-запуск-новых-образцов). Затем:

```bash
python scripts/validate_manifest.py --config config/herd2026.local.yaml --lightweight
python scripts/check_config.py --config config/herd2026.local.yaml --require-image
snakemake -s workflow/Snakefile \
  --configfile config/herd2026.local.yaml \
  --profile profiles/vavilov-fast --dry-run
```

Последняя команда — **только для Vavilov**; на ином кластере используйте адаптированный профиль. Dry-run строит DAG, не выполняя выравнивание или вызов вариантов.

## 3. Синтетический тест

Руководство: [синтетический положительный тест](README_positive_test.md). Его нужно генерировать перед запуском: `config/demo_positive.yaml` в Git не хранится.

## 4. Реальные технические пилоты

| Дата | Запуск | Проверенный результат |
|---|---|---|
| 22.10.2026 | `real_sif_20261022` | Три BAM, три индексированных VCF, QC, MultiQC и 81 chromosome BCF |
| 23.10.2026 | `real_sif_perf_20261023` | `101/101`, 9 ч 11 мин, три BAM, три VCF, MultiQC, 96 benchmarks; trimmed FASTQ и lane BAM автоматически удалены |

Тестовые данные включали один WGS КРС, один WGS овцы и один lpWGS овцы. Новая реализация highcov теперь выдаёт **отдельный VCF на животное**. Предыдущие пилоты не являются end-to-end валидацией нового режима, поэтому перед реальными большими партиями требуется интеграционный тест с двумя highcov-образцами одного вида. Выравнивание WGS-овцы во втором запуске оказалось медленнее (405,1 против 267,9 мин), поэтому называть профиль `vavilov-fast` универсально более быстрым нельзя.

## 5. Что проверить перед научным использованием

- Соответствие полученных VCF референсу, списку contigs и списку образцов.
- Корректность GT/PL/DP/AD, фильтров и заголовка INFO/MQ (в пилоте было предупреждение `MQ should be declared as Type=Float`).
- Повторяемость variant calling и поведение после прерывания заданий.
- Схему технического и биологического QC, зависимости от покрытия, проверку индивидуального calling на нескольких образцах одного вида.
- Для lpWGS: отдельный подход к вероятностям генотипов, известным сайтам и импутации.

**Успешное завершение Snakemake не означает валидации биологической точности вариантов.**
